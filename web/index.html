Nuance

  • Preview is fast; Refine re-runs 8 steps at the preview seed. Change prompt or size to unlock a fresh generate.
  • Seeds advance from last + 1 unless you set one. {A|B} templates cycle variants per image.
  • Any width/height works; non-÷16 sizes generate slightly larger, then downscale (yellow warning).
  • Upload captions the image into the form — it does not run img2img.
  • Natural-language prompts beat tag soup. Describe hands, faces, and lighting explicitly.
